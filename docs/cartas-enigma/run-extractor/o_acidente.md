# O acidente

**Nível de dificuldade:** Difícil

## Descrição

Um homem dirigindo um carro provoca um acidente ao colidir com uma bicicleta, ao fazer uma curva inesperada em um cruzamento. Quando os policiais chegam, outro homem é preso. Aquele que estava dirigindo é levado para casa.

## Solução

O condutor do carro estava numa aula prática da autoescola e seu instrutor lhe disse para fazer uma curva incorreta em um cruzamento, batendo em uma bicicleta. Os policiais julgaram o instrutor responsável pelo acidente, de modo que o prenderam e levaram o aluno para casa.
